# 验证结果与限制

测试日期：2026-10-03。环境：Windows 11 x64，CPU 模型线程数 2。

## 已验证

- 自包含 Release 发布，界面与工作进程均可运行。
- MMDevice 枚举、设备通知、Windows 音频转换为 16 kHz 单声道 float32。
- 自动预加载与推理预热，无 Start 时不采集音频、不创建课堂 TXT。初始化实测约 4.35–8.92 秒。
- 连续两次麦克风短录音复用同一模型，ModelLoads=1；开始到 Ready 分别为 1.532 秒、0.278 秒。
- 正常停止脚本排空音频、提交尾部并刷新 UTF-8 文件；正常退出释放模型。
- 多控制连接、重连、工作进程单实例、UI 单实例重定向；缺失模型和不可写目录正确报错。
- 实际 XAML 浅深色界面、加载状态、停止状态、紧凑错误恢复、设置与历史。实测 DPI 120／缩放 125%，PerMonitorV2 生效。
- 同一句说两遍保存两条，重连后的同一结果不重复展示，临时文字不逐字追加。
- 30 秒静默不产生最终文字，随后讲话无尾部静音也能在停止时提交。

## 连续回放与资源

601.75 秒工程音频实时回放通过：70 次讲话、70 个唯一最终结果、70 行 TXT，零错误事件。素材为官方短样本重复，不是真实课堂录音。

工作进程 CPU 平均 12.1%（按整机逻辑处理器归一化），峰值内存 789.2 MB。音频块交给识别队列到 Partial 事件平均 746 ms、最高 1110 ms；该值不包含模型 1120 ms 分块等待、采集和 UI 调度，不能作为端到端字幕延迟。

- 未获得真实课堂音频，尚未完成真实课堂十分钟、印度／中东口音、专业词、漏句率或词错误率验收。
- 未进行磁盘满、写入中断、设备拔出、权限拒绝或断电的破坏性测试。仅在内存中的尾句无法保证崩溃恢复。
